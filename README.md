# 🔬 DermAI 360° — Precision Dermatology AI & Targeted Cellular Diet Intelligence

An advanced clinical AI platform for skin disease detection and precision cellular nutrition using **EfficientNetB3** transfer learning (HAM10000 / ISIC dataset) expanded to **12 comprehensive skin pathologies**. The platform pairs diagnostic prediction with **condition-specific cellular diet protocols**, **deep clinical pathophysiology**, **9-language localization (including Kannada - ಕನ್ನಡ)**, and an **interactive clinical command center dashboard**.

## ⚡ Quick Start

### 1. Run the Web Dashboard
```bash
python app.py
```
Open **http://localhost:5000** in your browser.

> **Tip**: Click any of the **12 benchmark sample chips** on the top ribbon (Melanoma, Basal Cell, Acne, Eczema, Psoriasis, Vitiligo, etc.) to immediately test the AI analysis and generate a targeted diet plan!

### 2. Command-Line Inference (CLI)
```bash
python predict_cli.py data/HAM10000/images/SAMPLE_acne.jpg
```
Outputs the full clinical diagnosis, differentials, and the targeted cellular nutrition plan directly in your terminal.

## 🌐 REST API Endpoints

| Endpoint | Method | Description |
|---|:---:|---|
| `/` | GET | Interactive Clinical & Diet Dashboard UI |
| `/api/predict` | POST | Diagnostic inference (Accepts base64, sample filename, or file upload) |
| `/api/samples` | GET | List of 12 benchmark lesion sample presets |
| `/api/sample-image/<file>` | GET | Serves sample dermoscopy images |
| `/api/diseases` | GET | Complete catalog of 12 diseases with clinical and diet profiles |
| `/api/diet/<condition>` | GET | Retrieve targeted diet plan for condition code or name |
| `/api/disease/<condition>` | GET | Retrieve full clinical profile for condition code or name |
| `/api/health` | GET | Server health and model status |
